# Stage 68: R6I-26 Long-context low-concurrency and index memory experiment：长上下文低并发与索引内存实验

## 交付

- 新增长上下文实验计划：2048/3072/3584 prompt tokens × shared/mixed/random，共 9 个场景。
- 并发从 R6I-25 的 16 降到 4；每轮 288 请求，两侧各执行 2 轮，共 1152 个正式请求。
- 两个声明式 active-admission overlay 使用相同的 Gateway 64 in-flight、16 upstream connections、
  admission target 8–64 和 vLLM `max-model-len=4096`。
- benchmark metrics window 新增 RSS 与 Go heap 的 start/peak/end/delta，支持观察 KV-aware 运行时的
  内存增量；没有把第三方 LRU 私有 bucket 误报为 exact hash-only bytes。

## 结果

- 纯 LB 与 KV-aware 均 576/576 成功；pooled TTFT P95 为 `173.74 -> 183.65 ms`，变化 `+5.71%`，
  bootstrap 95% CI `[+1.14%, +8.36%]`。
- KV-aware 的收益仍集中在部分长 shared 档；3072 shared P95 约下降 25.05%，但 3584 shared 上升
  43.96%，本阶段不提升为全局 promotion 结论。
- KV 576/576 为 available，random 场景的 zero cached-prefix 保持真实 miss 语义；degradation、
  short bypass 和 admission rejection 均为 0。
- KV arm 峰值相对 LB 平均高约 26.82 MiB RSS、23.65 MiB Go heap；这是 KV-aware 运行时额外内存的
  近似上界，不是 hash index exact bytes。

详细数据见 [`2026-08-16-r6i26-long-context-memory.md`](../experiments/2026-08-16-r6i26-long-context-memory.md)。
实验结束后已恢复 `load-balanced + admission off` 基线。
