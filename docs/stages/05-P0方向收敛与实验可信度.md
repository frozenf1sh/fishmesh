# 05｜P0 方向收敛与实验可信度

## 目标

在继续实现 scheduler 前修正信号语义、实验可信度和开源定位，避免做出“指标很多但调度
依据不成立”的 weighted Hybrid Scheduler。

## 决策

- 项目统一命名 FishMesh，定位为可解释请求调度实验平台；
- 当前 affinity 明确为 cooperative routing-key affinity，不宣称精确 KV-aware；
- 下一策略是 eligibility filter + bounded affinity + load spillover；
- time-sliced RTX 4060 的 GPU 指标只作为 node-level health；
- 累计 TTFT/Prefix Cache counters 只进入时间窗口评估；
- Evidence-based Diagnoser 不宣传为 autonomous Agent；
- 未来生产集成边界是 Gateway API Inference Extension EPP adapter；
- eBPF、自动 actuator、CRD 和 disaggregation 移出 MVP。

## 工程修复

- Gateway 显式错误配置不再静默回退默认值；
- Loadgen JSONL 首条增加 run metadata；
- `artifacts/` 纳入证据管理，失败 attempt 和 rerun 同时保存；
- 历史 Hot Prefix 第一次 196/200 与 rerun 200/200 同时披露；
- 新增重复、随机化、窗口 counter delta 和统计区间实验规范；
- vLLM 从历史 0.11.0 升级到 0.23.0，旧镜像保留回滚；
- NVIDIA device plugin 更新到 0.19.2。

## 下一步

实现 P1 RequestContext、per-field Sample、bounded affinity、spillover、circuit breaker 和
endpoint 状态回收，再按新方案重新运行 benchmark。
