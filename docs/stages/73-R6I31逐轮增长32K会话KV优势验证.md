# R6I-31：逐轮增长 32K 会话的 KV 优势验证

## 交付

- `fishmesh-client bench` 新增 stateful conversation ladder：同一用户将真实上一轮 assistant 输出带入下一轮，
  不用 synthetic prefix 伪造 cache hit；
- 增加 3 用户 × 7 轮、最高 31,479 tokens 的正式配置与 LA/KV overlays；
- runner 每 arm 强制唯一 vLLM/Gateway pod-template rollout，按 Deployment generation + Ready replica gate
  等待，KV arm 额外验证两个 replay backend valid，避免旧 Pod 或上一 arm 的 KV cache 污染；
- 运行双 replicate、反向顺序对照并自动恢复 `load-aware + admission off + 4096` 基线。

## 验收结果

v3 正式运行的四个 arm 全部 21/21 成功。KV-aware 的 pooled TTFT P95 为 1771.68 ms，load-aware 为
3973.91 ms，delta -55.42%，bootstrap 95% CI [-67.28%, -31.52%]。KV 两轮均为 21/21 available，末轮每请求
27,376 cached-prefix tokens、约 4,103 uncached tokens；这确认的是 persistent long-conversation locality，
而不是短/随机混合负载上的通用收益。
