# 01｜真实观测适配器与诊断缺口

## 目标

让 Cluster Analyst 从真实的 Gateway、vLLM、GPU 和 Kubernetes 只读数据开始工作，缺少
数据时明确返回 `insufficient_observability`，不使用样例值冒充生产状态。

## 实现

- vLLM `/metrics`：queue、running、TTFT、Prefix Cache；
- GPU/DCGM Prometheus：利用率、显存、温度、OOM；
- namespace-scoped Kubernetes Events/Pods；
- eBPF 仍显式为 unavailable；
- Analyst 使用最小 ServiceAccount Role，只读 Events/Pods。

## 验证

在 K3s observability overlay 中，vLLM 和 Kubernetes signal 返回 `ok`；GPU/eBPF 缺失时，
规则策略返回 `insufficient_observability`，并建议补全观测，而不是误判 Prefix Locality。

## 边界

本阶段只读，不执行扩缩容、删除 Pod 或修改路由；也不让 LLM 进入请求路径。
